## Key Design Elements

### Colors & Theme

- **Background**: Pure white (#ffffff)
- **Cards**: White with subtle gray border (#e5e7eb)
- **Text Primary**: Dark gray (#1a1a1a)
- **Text Secondary**: Medium gray (#666666)
- **Accent Primary**: Blue (#3b82f6)
- **Accent Status**: Green success (#10b981), Red error (#ef4444)

### Spacing & Layout

- **Max-width**: 1280px (responsive)
- **Grid**: 2-4 columns on desktop, 1-2 on mobile
- **Padding**: 6, 4, 2 (Tailwind units = 24px, 16px, 8px)
- **Gap**: Consistent 4-6 units between elements
- **Rounded corners**: 8px (lg in Tailwind)

### Typography

- **Heading**: 24px bold (Metrics Dashboard)
- **Subheading**: 14px medium (Desktop info)
- **Card Title**: 14px semibold
- **Card Value**: 24px bold
- **Card Label**: 12px medium gray

### Visual Indicators

- **Icons**: Lucide React (24-32px)
- **Progress bars**: Full width with color coding
- **Charts**: Recharts with consistent colors
- **Status badges**: Color-coded with icons

```
Dashboard
├── Header
│   ├── Title
│   ├── Subtitle
│   ├── Timestamp
│   └── Agent Tabs (buttons)
│
├── StatusCard (full width, 2x height)
│   ├── Status Icon
│   ├── Status Label
│   ├── Duration
│   └── Cost
│
├── MetricCard Grid (4 columns)
│   ├── MetricCard (Tokens)
│   ├── MetricCard (Duration/Slides)
│   ├── MetricCard (Success/Components)
│   └── MetricCard (Quality/Overall)
│
├── Chart Grid (2 columns)
│   ├── TokenBreakdownChart (Bar)
│   ├── QualityScoresChart (Radar)
│   ├── ResourceChart (Dual Bar)
│   └── CoverageChart (Pie)
│
├── Details Grid (3 columns or 2 columns)
│   ├── DetailCard (Ingestion/Slides)
│   ├── DetailCard (Generation/Diagram)
│   └── DetailCard (Assembly/Duration)
│
└── Footer
    └── Copyright & Info
```

## Responsive Behavior

### Desktop (1024px+)

- 4 columns for metric cards
- 2 columns for charts
- Full sidebar details
- All information visible

### Tablet (768px - 1023px)

- 2 columns for metric cards
- 2 columns for charts
- Single column details
- Optimized spacing

### Mobile (< 768px)

- 1-2 columns for metric cards
- 1 column for charts
- 1 column for details
- Optimized touch targets
- Vertical scrolling
